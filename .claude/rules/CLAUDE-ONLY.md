# Claude-only policy

Claude/Claude Code is the only assisted-engineering and operational-agent runtime authorized in this repository.

- Do not create or restore .codex, AGENTS.md Codex instructions, CODEX_* manifests, Codex runtime, Codex skills or Codex workflows.
- All agents, skills, contracts, workflows, rules, hooks and runtime definitions live under .claude.
- Historical Git commits may contain removed Codex artifacts; current-tree runtime and documentation must not depend on them.
