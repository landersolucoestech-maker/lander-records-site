# Finding engine

Implementation: `runtime/findings.mjs`, `runtime/lib/findings.mjs`, contract `contracts/finding.schema.json`.
- Create from auditors (TRIAGED/READY with root cause) or sensors (DISCOVERED, deduped by signal fingerprint).
- Dedupe by invariant + producer; mark DUPLICATED with a pointer note.
- Every transition validated against kernel/state-machine.md and recorded in history.
- `state/findings.yml` is a derived index (regenerated by the CLI; pack.mjs fails if stale).
