# Claude Commands

/audit — repository/domain audit with evidence
/investigate — root-cause and dependency investigation
/plan — bounded implementation plan
/implement — implement approved/explicit scope
/fix — investigate and fix a defect
/refactor — behavior-preserving refactor
/review — adversarial code/security review
/test — targeted and blast-radius tests
/visual-audit — browser/responsive/visual validation
/security-audit — auth, authorization, secrets, inputs and dependencies
/validate — lint/typecheck/tests/build/runtime as applicable
/quality-gate — full completion gate
/release-check — release readiness and rollback evidence
/automation-audit — inspect workflow safety, idempotency, approvals and recovery

Each command routes through lander-records-site-orchestrator and must use the registries rather than inventing capabilities.
