# Evidence manager

`runtime/evidence.mjs` is the only way to create evidence: `run` executes a command (no shell) and records exit code, output hash/excerpt, commit, content fingerprint and environment (Node version vs engines); `review` records an independent reviewer report whose **last line** is `VERDICT: PASS|FAIL`. Records are created with O_EXCL (no id races) and linked in a sha256 hash chain (`prevHash`/`hash`), verified by pack.mjs and completion — hand-written or edited records break the chain. Criterion ids must belong to the active mission; finding ids must exist. A command that changes the workspace while running is rejected. Fresh = fingerprint equals the current workspace (OS record directories excluded). Timeouts are FAIL; only missing binaries/permissions are BLOCKED.
