# Execution protocol

Lifecycle: PREFLIGHT → DISCOVER → UNDERSTAND → FORMALIZE → PLAN → EXECUTE → VERIFY → REVIEW → REPAIR (if needed) → COMPLETE.

For implementation requests, perform safe local work without pausing for routine confirmation. Replan after material new evidence. Stop before external, destructive, costly, production, credential, or materially scope-expanding actions unless explicitly authorized. Never call work complete when mandatory evidence is missing or stale.

Before the first repository mutation, preflight is mandatory. When a local development server is detected/configured, Localhost Guardian health becomes a completion invariant.
