# Infrastructure examples

Os exemplos deste diretório cobrem processo Next.js de longa duração, reverse proxy, configuração de ambiente e backup PostgreSQL. Eles são templates de referência e não comprovam a topologia do ambiente real. O destino autorizado é Hostinger; use estes exemplos apenas quando o produto Hostinger contratado expuser um runtime compatível com processo Node.js persistente e os controles necessários.

Revise `docs/PRODUCTION_INFRASTRUCTURE.md`, `docs/DEPLOYMENT.md`, `docs/DEPLOYMENT_RUNBOOK.md`, `docs/ENVIRONMENT_CONTRACT.md` e `docs/ROLLBACK_RUNBOOK.md`, `docs/HOSTINGER_DEPLOYMENT_CONTRACT.md` antes de adaptar ou instalar qualquer exemplo.
